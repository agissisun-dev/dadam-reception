# 으라 — 고객 상담 카드 1차 개발 범위

출처: customer-view-os-workshop `03_수업자료/3시간_참가자별_1차개발범위.md` (으라 항목)
원문 기획안: [01_으라_기획안_원문.md](01_으라_기획안_원문.md)

## 대상
헤어원네스트 이은 원장 (1인 미용실, 월 175명, 재방문 주기 3~4개월)

## 원안의 핵심 가치
- 고객이 나간 뒤 **음성 30초 + 사진 2장**으로 상담 기록이 끝난다.
- 재방문 때 카드를 열면 지난 기록과 사진이 바로 보인다.
- 퇴근 후 수동 입력 월 10~12시간을 회수한다.
- AI는 고객 앞이 아니라 원장 뒤에서만 돕는다. 핸드SOS(기존 CRM)는 유지한다.

## 오늘(1차) 완성할 것
- 예시 고객 이름 또는 식별명, 상담일, 자유 메모 하나를 저장한다.
- 저장한 상담을 고객별로 모으고, 다시 열어 수정한다.
- 필수 입력 칸을 더 늘리지 않는다.

## 입력 방식
- 휴대폰·PC에 이미 있는 받아쓰기 기능으로 메모를 입력한다.
- 앱 안에서 녹음을 받아 음성 변환 API로 보내는 기능은 다음 단계.

## 완료 확인 기준
- 예시 고객 두 명을 등록한다.
- 한 고객의 지난 상담을 찾아 수정한다.
- 새로고침해도 데이터가 남아 있다.

## 1차에서 제외
- 음성 파일 보관, 앱 내 AI 자동 정리
- 전후 사진 업로드·클라우드 저장
- 기존 13년 데이터 이관, 핸드SOS 예약 연동
- 알림톡 발송

## 시간이 남으면 하나만
- 상담 메모 전체 복사

## 다음 단계 후보 (하나씩)
- 사진 저장 위치와 권한
- 음성 변환 또는 AI 정리 중 한 가지
- 알림톡은 예약 데이터가 어디서 오는지 확인한 뒤
