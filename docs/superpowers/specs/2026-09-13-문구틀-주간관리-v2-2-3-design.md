# 다담 접수실 앱 V2-2 안내문 틀 · V2-3 주간 환자 관리 문자 설계

작성일: 2026-09-13
출처: [기획안 원문](../../01_다담_접수실앱_기획안_원문.md) §2(주간 환자 관리), §3(반복 업무), §5(카카오 복사·붙여넣기), §7(개인정보) · V1·V2-1 설계
브레인스토밍 결정: 대상 지정은 환자 상세에서 접수실이 켜고 끔. 답변 메모 + 원장 확인 대기 목록까지 포함. 기본 요일 화요일, 회차는 4주차까지(이후 4주차 문구 반복).

## 1. 목표와 핵심 질문

- V2-2: 접수실이 반복 업무 안내문을 매번 새로 쓰지 않는다. 등록 때 틀을 고르면 채워진다.
- V2-3: 내원이 끊긴 환자에게 주 1회 상태 확인·식단 점검·내원 안내 문자를 빠짐없이, 회차마다 다른 문구로 보내고, 환자 답변을 원장이 확인해 다음 문구에 반영한다.

**핵심 질문 (V2-3):** 접수실이 화요일 아침에 주간 관리 화면만 보고, 이번 주 보낼 사람·문구·지난주 답변·원장 지시를 한 줄에서 보고 처리할 수 있는가.

원칙: 발송은 사람이 한다(복사 → 카카오 채널). 자동 휴면 없음. 문구는 치료 안내 범위.

## 3. 규칙

- **다음 발송일**: 시작 시 = 오늘 이후 첫 번째 지정 요일(오늘이 그 요일이면 오늘). [발송함]/[내원해 건너뜀]/[답 없음] 후 = 현재 예정일 + 주기×7일. 예정일이 지났으면 "N일 지남" 표시.
- **회차**: [발송함]이면 +1. [내원해 건너뜀]·[답 없음]은 회차 유지(같은 문구를 다음 주 다시). 5회차 이상은 4주차 문구를 쓴다.
- **이번 주 문구 고르기**: templates에서 kind='weekly', condition=환자 질환, round=min(회차,4) 인 것. 없으면 condition=null 공통 문구. 그것도 없으면 빈 칸. 원장 지시(doctor_note)가 있으면 문구 아래에 "원장님 지시: …"를 붙여 보여 주되 본문에는 자동 삽입하지 않는다(접수실이 읽고 문장에 녹임).
- **무응답 배지**: 최근 기록에서 연속 'no_reply' 횟수 ≥ 4면 "무응답 N주" 붉은 배지. 자동 휴면 없음.
- **휴면**: weekly_status='dormant', 명단에서 빠짐. [주간 관리 시작]으로 복귀(회차 1부터 다시 시작할지 이어갈지: 이어감).
- **연락 제외**: 해피콜의 연락 제외와 같은 excluded_at 사용. 주간 관리도 함께 멈춤(weekly_status='off').

## 4. 화면

### ① 문구 틀 (`/templates`) — 상단 바 [문구 틀]
- 탭 두 개: [업무 안내문] [주간 관리 문구].
- 업무 안내문: 목록(이름·기본 제목·날짜 규칙), [새 틀], 편집(이름·기본 제목·본문·날짜 규칙), 삭제(확인 창).
- 주간 관리 문구: 질환 × 회차 표 형태. 칸을 누르면 편집. [공통 내원 안내]도 한 칸.

### ② 업무 등록 (`/tasks/new`) 수정
- 맨 위 "틀에서 시작" select. 고르면 제목·안내문 채움, 날짜 힌트 표시. 이후 자유 수정.

### ③ 주간 관리 (`/weekly`) — 상단 바 [주간 관리]
- 탭 [이번 주] [확인 대기].
- **이번 주**: `weekly_status='active'`이고 `weekly_next_date <= 이번 주 일요일`. 요일별 묶음, 지난 것 붉게.
  - 줄: 이름, 질환, N회차, 다음 발송일, 무응답 배지, 연락처(펼치면 전체).
  - 펼치면: 지난 기록 최근 1건(보낸 문구·답변·원장 지시), **이번 주 문구**(textarea, 틀에서 자동 채움) + [문구 복사], 처리한 사람, 버튼 [발송함] [내원해 건너뜀] [답 없음 → 다음 주] [휴면] [연락 제외].
  - [발송함]: message 저장, 회차 +1, 다음 발송일 계산.
- **확인 대기**: reply_status='waiting_doctor'인 기록. 환자·회차·보낸 문구·답변. 원장 지시 입력 + [확인 완료] → reviewed.
- 답변 기록: 이번 주 줄과 환자 상세의 기록에서 [답변 기록] → 메모 → [원장님 확인 요청] 체크 → 저장.

### ④ 환자 상세 수정
- [주간 관리 시작] → 요일·주기 선택 → 시작. 활성 중이면 "주간 관리 중 · 화요일 · 매주 · 3회차 · 다음 9/16" 표시와 [중지]. 휴면이면 [다시 시작].
- 주간 관리 기록 목록(회차·날짜·처리·문구·답변·지시).

### ⑤ 첫 화면 카드 추가

## 5. 초기 문구 (seed, 접수실이 고쳐 씀)
- task 5개: 추석 휴진 안내, 설 휴진 안내, 다음 달 달력 업로드, 한방파스 재고 확인, 명절 선물 안내문.
- weekly: 소화기 1~4주차, 피부 1~4주차, 일반 1~4주차, 공통 내원 안내 1개 = 13개.

## 6. 완료 확인
1. 업무 등록에서 "추석 휴진 안내" 틀 선택 → 제목·안내문 채워지고 힌트 표시. 틀 화면에서 본문 한 줄 고친 뒤 다시 선택하면 고친 문구.
2. 가짜 환자(소화기)에 [주간 관리 시작] 화요일·매주 → 다음 발송일이 다가오는 화요일. 이번 주 명단에 뜸(이번 주 안이면).
3. 문구가 "소화기 1주차" 틀로 채워짐. [발송함] → 회차 2, 다음 발송일 +7일, 기록에 보낸 문구.
4. [답변 기록] "식단 보냄" + 원장 확인 요청 → 확인 대기 탭에 뜸. 지시 "저녁 밀가루 줄이기" + [확인 완료] → 다음 주 줄에 지시 표시.
5. [답 없음] 4번 → "무응답 4주" 배지. [휴면] → 명단에서 빠짐. 환자 상세 [다시 시작] → 복귀.
6. 새로고침 후 동일. 가짜 데이터 삭제.
