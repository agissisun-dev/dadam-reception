# 문자 발송 설정 (솔라피)

앱의 해피콜·주간 관리 줄에서 [문자 보내기]를 누르면 접수실 화면에서 바로 문자가 나갑니다.
문자 업체 키를 넣기 전까지는 버튼을 눌러도 "문자 설정이 아직 안 되어 있습니다"라고만 안내합니다.

## 1. 솔라피 가입과 발신번호 등록 (원장님이 한 번)
1. https://solapi.com 회원가입 → 콘솔 로그인.
2. [발신번호 관리] → 병원 대표번호 등록. 사업자등록증과 통신서비스 이용증명원(통신사에서 발급)이 필요합니다. 승인까지 보통 1~2일.
3. [충전] 에서 소액 충전. 짧은 문자(SMS) 건당 20원 안팎, 긴 문자(LMS) 50원 안팎.
4. [API Key 관리] → 새 키 발급 → **API Key**와 **API Secret** 두 값을 복사.

## 2. Vercel에 키 넣기 (원장님이 직접, 다른 사람에게 보내지 않는다)
1. https://vercel.com → dadam-reception 프로젝트 → Settings → Environment Variables.
2. 아래 세 개를 Production에 추가. 이름 앞에 `NEXT_PUBLIC_`을 붙이면 브라우저에 노출되니 **붙이지 않는다**.

| 이름 | 값 |
|---|---|
| `SOLAPI_API_KEY` | 솔라피 API Key |
| `SOLAPI_API_SECRET` | 솔라피 API Secret |
| `SMS_SENDER_NUMBER` | 등록한 발신번호, 숫자만 (예: 0212345678) |

3. 저장 뒤 다시 배포: `npx vercel deploy --prod --yes` (환경 변수는 새 배포부터 적용됩니다).

## 3. 확인
1. 앱 해피콜 화면에서 환자 줄을 펼치고 [문자 보내기] → 받는 사람 확인 → [보내기].
2. 원장님 휴대폰을 환자 연락처로 둔 시험 환자로 먼저 보내 본다. **끝나면 시험 환자는 지운다.**
3. 보내면 그 해피콜은 "연락함(문자)"으로 기록되고, 기록 메모에 보낸 문구가 남는다. 주간 관리는 "발송함"으로 기록되고 회차가 올라간다.
4. 실패하면 화면에 "문자를 보내지 못했습니다. …"와 업체가 준 이유가 뜬다. 발신번호 미승인, 잔액 부족이 흔한 이유.

## 동작 방식 (참고)
- 브라우저 → 앱 서버(`app/api/sms/route.ts`, Vercel에 함께 배포) → 솔라피. 업체 키는 서버에만 있다.
- 서버는 로그인 토큰을 확인해 로그인한 사람만 보낼 수 있게 한다.
- 받는 번호는 휴대폰(01로 시작, 10~11자리)만. 문구는 90바이트까지 SMS, 그 위는 LMS(최대 2,000바이트)로 자동 구분. `lib/smsRules.ts`
- 솔라피 규격이 바뀌면 `app/api/sms/route.ts` 한 파일만 고치면 된다. 이 세션에서는 업체 문서 사이트에 접속할 수 없어 알려진 규격(`/messages/v4/send`, HMAC-SHA256 서명)으로 만들었다. 첫 시험 발송이 실패하면 그 화면 문구를 그대로 알려 주면 된다.

## 환자 답장
일반 문자의 답장은 병원 전화기로 온다. 앱은 보낸 기록만 남기고, 답변은 지금처럼 주간 관리의 [답변 기록]에 적는다.
카카오 알림톡으로 바꾸고 싶으면 같은 솔라피 계정에서 카카오 채널 연결과 문구 심사를 받은 뒤 서버 파일만 바꾸면 된다.
