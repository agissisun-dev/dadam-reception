# 약대장 (탕전 일정) V5 — 설계

작성 2026-10-02. 엑셀 「26년약대장」(주 단위 월~토 표)을 앱으로 옮긴다. 접수실이 환자와 상의해 달이는 날을 잡고, 탕전실은 그 일정대로 달인다(사용자 2026-10-02). 장기적으로는 DK처럼 탕약 처방 내용과 약재 관리까지 넓힌다. 이번 범위는 **일정**까지.

## 1. 목적과 범위

- **목적**: 접수실이 수납할 때 잡은 탕전 일정이 약대장에 자동으로 들어가고, 탕전실은 앱 화면을 보고 달인다. 엑셀 약대장 창이 없어진다. 받는 날이 정해지므로 해피콜 날짜가 정확해진다.
- **범위 안**: 약대장 화면(주 단위 월~토, 오전/오후), 오늘 장부 탕약 줄 → 약대장 자동 등록, 손으로 넣는 칸(묶음 생산·메모·환자 없는 건), 끝남 표시, 날짜 옮기기(→ 처방 수령일·해피콜 따라감), 발효 시작/끝 짝, 분할 수령 2회분, 날짜 미정 목록.
- **범위 밖(다음 단계)**: 처방 내용(약재·첩수), 약재 재고, 탕전실 전용 로그인, 택배 송장.

## 2. 엑셀에서 읽은 것 (26년약대장.xlsx, 2020약대장 시트)

- 한 주가 한 블록: `월|화|수|목|금|토` 줄, 날짜 줄(`1월6일`), 그 아래 그날 달일 것이 한 칸에 하나. 일요일은 없음.
- 칸 글 모양: `이름님-종류-받는 방법(지역)` + 꼬리표.
  - 종류: `보험(처방)` · 일반 · `발효` · `시간탕` · `보험(소화.3)`·`보험(디스크.2)`(회차 붙음) · `자보#,1` · `#,1`/`#2`(분할 회차) · `해수환15일` 같은 환제.
  - 받는 방법: `직`(직접 수령. `화 오전 직`, `토.직`처럼 요일·시간 붙음) · `택`(택배. `택(광명)`처럼 지역) · `월.택`.
  - 꼬리표: `파-다담`·`파-애장금`·`파-자연과사람`·`파-공룡`(+`@`) → 포장(파우치) 종류로 보임(확인 필요). `(냉장보관)`, `쌍화탕20p동봉`, `소합원같이` 같은 메모.
  - `직o` / `직0`의 `o` = 끝남 표시. `재고38` = 그 처방 묶음의 남은 수.
- `발효시작` ↔ `발효끝-택` 짝. 엑셀에서는 보통 2~3일 간격(확인 필요).
- `↓(오후)↓` 아래는 오후 작업. `디스크 100팩` · `소화 100팩` · `디스크 40팩` = 묶음 생산. `탕쌤 월차(1)` · `탕쌤 4시 퇴근` · `지방택배마감`·`서울택배마감`·`택배X / 직-가능` = 메모.

## 3. 데이터 (`supabase/schema-v5-brew.sql`)

```
brew_jobs                       탕전 일정 한 칸
  id, day date null              달이는 날 (null = 날짜 미정)
  slot text 'am'|'pm' default 'am'
  kind text check in ('decoction','ferment_start','ferment_end','batch','note')
  patient_id bigint null → patients (set null)
  patient_name text              이름 (환자 없는 메모면 빈 문자열)
  title text                     종류 글: 보험(처방) · 일반 42만원 · 발효 · 시간탕 · 보험(소화.3) · 디스크 100팩 · 택배 마감 …
  delivery text null 'pickup'|'courier'
  region text null               택배 지역 / 직접이면 "화 오전" 같은 시간 메모
  pouch text null                파-다담 등
  split_no int null, split_of int null   분할 회차 (#1 of 2)
  memo text null
  status text 'planned'|'done' default 'planned', done_at timestamptz null, done_by text null
  prescription_id bigint null → prescriptions (set null)
  ledger_entry_id bigint null → ledger_entries (set null)
  pair_id bigint null → brew_jobs (set null)     발효 짝(시작 ↔ 끝)
  sort_order int default 0, staff_name text, created_at, updated_at
```
- RLS: authenticated 전부(읽기·쓰기). 일정은 자주 옮기므로 잠그지 않는다. 끝남 표시는 `status`·`done_at`·`done_by`로 남긴다.
- `prescriptions`에 `delivery text null`, `brew_day date null` 열을 더한다(수령일 계산 근거).

## 4. 규칙 (`lib/brewRules.ts`, 테스트)

- **칸이 놓인 날 = 달이는 날이고, 그날 나간다**(사용자 2026-10-02). **받는 날** = 직접이면 달이는 날, 택배면 달이는 날 + 1(일요일이면 월요일). 발효는 발효끝(포장·발송) 날 기준. 받는 날이 바뀌면 `updatePrescription`으로 해피콜 재계산(대기 중인 것만).
- **발효**: 사흘 걸린다(사용자 2026-10-02: 목요일에 달이면 목·금·토, 토요일에 포장해서 나감). `발효시작` 칸을 달이는 날에, `발효끝`(포장·발송) 칸을 **+2일**(셋째 날)에 짝(`pair_id`)으로 만든다. 셋째 날이 일요일이면 월요일. 짝 중 하나를 옮기면 상대도 같이 옮긴다.
- **분할 수령**(장부 `#2`): 1회분 칸을 달이는 날에 만들고, 2회분 칸은 `day null`(날짜 미정)로 만든다. 날짜 미정 목록에서 날짜를 넣으면 칸으로 들어간다. 받는 날(해피콜 기준)은 마지막 회차 받는 날.
- **칸 글 만들기** `jobLabel(job)`: `이름-종류-직/택(지역) 파-…` 엑셀과 같은 모양. 끝나면 끝에 `o`.
- **주 계산**: 월~토 6칸. 오늘이 일요일이면 다음 주를 보여 준다.
- **오전/오후**: 기본 오전. 오후는 `slot='pm'`, 화면에서 `↓(오후)↓` 구분선 아래.

## 5. 화면

### 5-1. 약대장 `/brew` (메뉴: 오늘 장부 다음)
- 위: ◀ 이번 주 ▶, 주 날짜 범위, [+ 칸 넣기](환자 없는 건·묶음·메모), "날짜 미정 N건".
- 본문: 월~토 6열. 열마다 날짜·휴진 표시, 오전 칸들, `↓(오후)↓`, 오후 칸들. 칸 = 작은 카드: 글(`jobLabel`), 종류별 색(보험 주황·일반·발효 초록·묶음 회색·메모 노랑), [끝남 o] 버튼, 누르면 펼쳐져 날짜·오전/오후·받는 방법·지역·메모 고치기, 짝·처방·장부 줄 링크.
- 끝난 칸은 회색 + `o`. 그날 "N건 중 M건 끝남".
- 아래: 날짜 미정 목록(분할 2회분, 아직 날 못 잡은 건).

### 5-2. 오늘 장부 탕약 줄 (바뀌는 것)
- 지금의 "약 받는 날" 칸을 **달이는 날**(필수) + **받는 방법**(직접/택배, 택배면 지역) + **포장(파-)**(선택, 자주 쓰는 것 datalist)으로 바꾼다.
- 저장하면 처방·해피콜과 함께 약대장 칸이 생긴다(발효면 짝, 분할이면 2회분 미정 칸). 미리보기에 "달이는 날 10/5(월) → 받는 날 10/6(화) → 해피콜 10/13 · 11/5"가 보인다.
- 포 수를 안 고르면 처방은 안 만들지만 약대장 칸은 만든다(탕전은 해야 하므로). 그 칸에 "포 수 없음" 표시.

### 5-3. 환자 상세 · 첫 화면
- 환자 상세 처방 이력에 "달이는 날 · 받는 방법" 표시, [수령일 바꾸기]는 그대로.
- 첫 화면 요약에 "이번 주 탕전 N건" 링크.
