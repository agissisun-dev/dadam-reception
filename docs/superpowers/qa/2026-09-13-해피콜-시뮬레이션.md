## 접수실 시뮬레이션 (이혜경샘이 됐다고 가정)

### 장면 1. 결제 때 환자 등록
- 손동작: [환자 등록] → 연락처 입력 → [확인] → 이름 → 질환 버튼 하나 → 수령일·일수 → [저장]. **클릭 7번, 입력 4칸.** 30초 안에 끝남.
- 좋은 점: 저장 전에 "1차 9/12 (토) · 2차 10/2 (금)"이 미리 보여서 접수실이 날짜를 머리로 계산할 필요가 없다. 재방문 환자는 연락처만 치면 "이미 등록된 환자"가 떠서 이름을 다시 안 친다.
- 걸리는 점 ①: 연락처를 치고 **[확인]을 한 번 더 눌러야** 다음 칸이 열린다. 접수가 밀릴 때는 이 한 번이 아깝다. → 연락처 11자리가 다 입력되면 자동으로 확인하도록 바꾸면 클릭 하나가 준다.
- 걸리는 점 ②: 수령 예정일 기본값이 "오늘+3"인데, 바로 가져가는 환자(당일 수령)는 매번 오늘로 고쳐야 한다. → "오늘 수령" 버튼 하나를 날짜 옆에 두면 된다.
- 걸리는 점 ③: 처방 일수를 30으로 미리 채워 두었는데, 다담은 15일·20일 처방도 있다면 자주 쓰는 일수 버튼(15·20·30)이 있으면 타이핑이 준다. **실제 처방 일수 분포를 접수실에 물어볼 것.**

### 장면 2. 아침에 해피콜 명단 보기
- 첫 화면 맨 위 "해피콜 대상 오늘 1명 · 지난 것 1명" 카드가 노란색으로 떠서 눈에 바로 들어온다. 누르면 명단.
- 명단은 오늘 것이 위, 지난 것은 붉은 "1일 지남". 한 줄에 이름·차수·질환·몇 번째 처방·메모가 있어 **전화 걸기 전에 뭘 말할지 안다.** 
- 걸리는 점 ④: 연락처가 가려져 있어 **줄을 펼쳐야** 번호가 보이고, 거기서 한 번 더 눌러야 전체 번호가 나온다(클릭 2번). 개인정보 원칙 때문이지만 접수실 PC는 원내망이라 과할 수 있다. → 펼쳤을 때는 바로 전체 번호를 보이게 하고, 목록(접힌 상태)에서만 가리는 절충안이 낫다.
- 걸리는 점 ⑤: 휴대폰이 아니라 PC에서 쓰면 "전화 걸기 링크"가 의미 없다. 접수실 데스크 전화로 걸어야 하므로 번호를 **복사** 버튼이 더 유용하다.

### 장면 3. 연락 결과 남기기
- [연락함] → 카톡 → 메모 한 줄 → 이름은 지난번 선택이 기억돼 있음 → [저장]. **클릭 3번, 입력 1칸.** 
- [안 받음]은 클릭 한 번으로 끝나고 내일로 넘어간다. 가장 자주 쓰는 동작이 가장 짧아서 맞다.
- 걸리는 점 ⑥: 메모가 비어 있어도 저장된다. 괜찮지만, 카톡을 보냈는데 답이 아직 없을 때 "카톡 보냄, 답 대기"처럼 쓰라는 안내 문구(placeholder)가 있으면 기록이 균일해진다.
- 걸리는 점 ⑦: [연락함] 뒤에 화면이 다시 그려지면서 펼쳤던 줄이 닫힌다. 여러 명을 연달아 처리할 때는 오히려 좋다(다음 사람이 위로 올라옴).

### 장면 4. 재처방·종료
- [재처방·예약됨] 메모에 "9/21 예약함"을 남기니 처방이 종료되고 명단에서 빠진다. 새 약은 환자 상세에서 [처방 추가]. 
- 걸리는 점 ⑧: 재처방 처리 직후 **바로 새 처방을 넣고 싶은 경우**가 많을 텐데, 지금은 환자 상세로 이동해서 [처방 추가]를 눌러야 한다. → 재처방 저장 뒤 "새 처방 바로 등록" 버튼을 띄우면 한 흐름으로 이어진다.

### 종합
- 복잡하지 않다. 하루 흐름은 "아침에 카드 보고 → 명단 열고 → 위에서부터 [연락함]/[안 받음]" 세 단계이고, 등록은 결제 때 30초다.
- 기획서의 "이중 입력을 만들면 앱이 짐이 된다" 원칙은 지켜졌다. 내원 여부를 따로 입력하지 않고, 재처방이면 종료 버튼 하나다.
- 위 걸리는 점 8개 중 **①(자동 확인), ②(오늘 수령 버튼), ④(펼치면 번호 표시), ⑧(재처방 후 바로 등록)**은 작은 변경이라 실사용 전에 넣는 것을 권한다. ③은 접수실에 물어본 뒤, ⑤·⑥·⑦은 써 보고 정한다.

## 반영 결과 (같은 날 저녁)

- 처방 입력을 **포 수**로 바꿈. 사용자 확인: 1일 2포, 20·35·40·70포가 보통. 일수 = 포 ÷ 하루 포수 올림. 35포 → 18일분, 해피콜 1차 +7·2차 +15.
- 걸리는 점 ①②④⑧ 반영. 배포 주소에서 확인: 연락처 11자리 입력만으로 자동 확인됨, [오늘 수령] 버튼 동작, 펼치면 번호 전체와 전화 링크 표시, [저장하고 새 처방 등록] → 환자 상세에 처방 폼 열린 채 이동.
