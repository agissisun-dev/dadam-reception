# 다담 접수실 앱 V9 내원 경로 설계

작성일: 2026-11-06
출처: 사용자 요청("접수실에 어떻게 오셨는지를 체크하는 기능. 유튜브면 어떤 영상인지, 블로그면 어떤 글인지. 정확하진 않아도 그런 내용이다 라고만 적으면 되게").

## 1. 목표
신규 환자가 어디서 왔는지 쌓아서, 유튜브·블로그 중 어떤 내용이 환자를 데려오는지 본다. 접수실 부담은 버튼 하나 + 한 줄.

## 2. 규칙
- 경로 후보: 유튜브 · 블로그 · 네이버 검색·플레이스 · 인스타그램 · 지인 소개 · 간판·지나가다 · 기타 (`lib/sources.ts`).
- 고르면 메모 칸이 열리고 자리 안내가 경로마다 다르다(유튜브 "어떤 영상이었는지 대략", 소개 "누가"). 비워도 된다.
- 선택 사항. 옛 환자는 비어 있고 환자 상세 [고치기]에서 채운다.

## 3. 구조
| 부분 | 파일 |
|---|---|
| 표 | `supabase/schema-v9-patient-source.sql` — `patients.source`·`source_note` |
| 등록 | `app/patients/new/page.tsx` 질환 분류 아래 |
| 장부 새 환자 | `components/LedgerEntryForm.tsx` 연락처 적으면 바로 아래, `lib/ledger.ts` saveEntry |
| 상세 | `app/patients/[id]/page.tsx` 표시 + 고치기 |
| 현황 | `app/stats/page.tsx` "신규 환자, 어떻게 오셨나 (최근 3개월)" 표, 규칙 `sourceCountsByMonth` (테스트) |

## 4. 확인 항목 (qa)
- SQL 실행 → 환자 등록에서 유튜브 고르고 "역류성 식도염 영상" 적고 저장 → 상세에 배지와 메모.
- 장부 새 환자(연락처 입력)에서 경로 고르고 저장 → 그 환자 상세에 보임.
- 현황 표에 이번 달 유튜브 1.
