# 예약차트 V7 — 설계

작성 2026-10-02. 접수실이 나갈 때 다음 예약을 잡고 안내 문자를 보내며, 네이버 예약도 같은 시간표에 **N** 표시로 들어오고, 아침에 오늘 올 사람을 보고 내원·노쇼·취소를 표시한다(사용자 2026-10-02 "1·2번 모두"). DK 예약관리(진료의·시간·이름·차트번호·연락처·내원 결과·메모, 누르면 자동 저장)를 참고하되 출처(N)와 수납 연결을 더한다.

## 1. 범위

- **안**: 시간표(15분 칸), 예약 잡기(접수실·해피콜·수납 뒤 다음 예약), 오늘 올 사람 목록과 내원·노쇼·취소, 내원 → 오늘 장부 줄, 예약 안내 문자(문구 틀 + 솔라피, 키 없으면 복사만), 네이버 예약 N 표시(손 입력 + 붙여넣기, 자동 연동은 길이 확인되면), 첫 화면 요약, 현황(내원율·노쇼).
- **밖**: 네이버 쪽에 상태를 되돌려 쓰기, 카카오 알림톡 템플릿 심사(신청은 같이 하되 발송은 승인 뒤), 노원다담 시간표(병원 칸은 있음, 시간은 시작할 때 넣음).

## 2. 시간표 규칙 (`lib/appointmentRules.ts`, 테스트)

- 다담에스(S) 기본: **월·화·목 9:30~18:00, 점심 13:00~14:00 / 토 9:30~15:00 점심 없음 / 수·금·일 휴진**(사용자 2026-10-02). 공휴일은 `lib/holidays.ts` 그대로. 노원(N)은 시작할 때 따로 적는다(`CLINIC_HOURS[clinic]`).
- **진료일은 그때그때 바뀔 수 있다**(사용자 2026-10-02: 토요일 10/3이 개천절이면 금요일 10/2에 진료). 표 `clinic_day_overrides(clinic, day, open bool, start, end, lunch_start, lunch_end, memo)`로 **그날만** 열거나 닫는다. 예약 화면 날짜 머리의 [이날 진료 바꾸기]로 접수실이 넣는다. 휴진으로 바꾸는 날 이미 예약이 있으면 붉게 경고하고 옮기게 한다.
- **칸 = 30분(설정값 `slotMinutes`, 15분으로 바꿀 수 있음. 바꾸면 정원도 같이 조정).** 한 칸에 **침치료 3명 + 초진·약상담 1명**(사용자 2026-10-02).
- **잡는 방법 = 빈칸 누르기**(사용자 2026-10-02 "네이버 예약처럼"): 달력에서 날짜 → 그날 시간표 → 상담 열의 빈칸을 누르면 상담, 침 열의 빈 자리를 누르면 침. 작은 창에 이름(자동완성)·메모만 넣는다. 시간·종류는 누른 칸이 정한다. 상담이 찬 칸은 상담은 더 못 잡고 침은 3명까지. 꽉 찬 칸에 꼭 잡아야 하면 "그래도 잡기"로 넘길 수 있고 그 칸은 붉게 보인다(약대장 한도와 같은 생각: 막지 않고 보이게).
- 칸 글: `시간 · 이름 · 종류` + 출처 표시(N = 네이버, 해 = 해피콜에서, 수 = 수납 뒤 다음 예약). 상태: 예약 · 내원 · 노쇼 · 취소.
- 하루 요약: 예약 N명(상담 a · 침 b), 내원 c, 노쇼 d.

## 3. 데이터 (`supabase/schema-v7-appointments.sql`)

```
appointments
  id, clinic text default current_clinic(),
  day date not null, time text not null ('09:30' 같은 HH:MM, 30분 단위),
  kind text check in ('consult','treatment') not null,
  patient_id bigint null → patients (set null), patient_name text not null, phone text null,
  source text check in ('desk','naver','happycall','ledger') default 'desk',
  status text check in ('booked','arrived','noshow','cancelled') default 'booked',
  memo text null,
  naver_key text null unique            -- 네이버 예약 번호(붙여넣기·연동 때 중복 방지)
  happy_call_id bigint null → happy_calls (set null),
  ledger_entry_id bigint null → ledger_entries (set null)   -- 내원 뒤 수납 줄
  notified_at timestamptz null, notify_note text null         -- 안내 문자 보낸 시각·방법(문자/카카오/복사)
  staff_name text not null, created_at, updated_at
  unique (clinic, day, time, patient_name, kind)
```
clinic_day_overrides
  clinic text default current_clinic(), day date, open boolean not null,
  start text null, "end" text null, lunch_start text null, lunch_end text null, memo text null,
  primary key (clinic, day)
```
- RLS: 병원별(`clinic = current_clinic()`), 읽기·쓰기 모두.
- `templates`에 kind `'appointment'` 추가(문구 틀 종류): "예약 안내" 틀 1개. 자리표 `{이름}` `{날짜}` `{시간}` `{병원}`. 내용은 접수실이 고침.

## 4. 화면

### 4-1. 예약 `/appointments` (메뉴: 약대장 다음)
- 위: ◀ 날짜 ▶ 오늘, [+ 예약], [네이버 붙여넣기], [내일 예약 안내 보내기].
- **왼쪽 달력**(사용자 2026-10-02 "예약 잡는 건 달력으로"): 한 달 달력, 날짜마다 예약 수, 휴진은 회색, 그날만 진료로 바꾼 날은 주황. 날짜를 누르면 가운데 시간표가 그날로 바뀐다. 아래 [이날 진료 바꾸기](휴진 ↔ 진료, 시간). 첫 화면 달력(`MonthCalendar`)과 같은 틀을 쓴다.
- 왼쪽 **시간표**: 9:30부터 30분 칸. 점심·휴진 칸은 회색. 칸마다 상담 자리 1(굵게)과 침 자리 3(칩). 칸을 누르면 그 시간에 새 예약(이름 자동완성 → 환자 연결, 종류 기본 침, 출처 접수실, 메모). 꽉 찬 칸은 "상담 꽉 참"·"침 3/3"으로 보이고 "그래도 잡기"가 있다.
- 오른쪽 **오늘 올 사람**: 시간순 목록. 줄마다 [내원] [노쇼] [취소]. **[내원]** 을 누르면 상태가 바뀌고 오늘 장부로 가서 새 줄에 이름이 미리 들어간다(`/ledger?name=…&appt=…`); 저장되면 예약에 `ledger_entry_id`가 붙어 "수납 끝"으로 보인다.
- 예약 줄을 누르면 시간·종류·메모 고치기, 다른 날로 옮기기, [안내 문자 보내기].

### 4-2. 수납 뒤 다음 예약 (오늘 장부)
- 줄 저장 뒤 줄 끝에 **[다음 예약]**. 누르면 작은 창: **작은 달력**에서 날짜 고르기(날짜마다 예약 수·휴진 표시, 기본 선택 없음 — 샘이 환자와 정한 날) → 그날 시간표가 창 안에 펼쳐지고 **빈 자리를 누르면** 그 시간·그 종류로 잡힌다(이름은 그 환자로 이미 채워짐). 저장 → 출처 `ledger` → 안내 문자.
- 해피콜 줄의 **재처방·예약됨**을 누르면 같은 창이 뜬다(출처 `happycall`, `happy_call_id` 연결). 날짜를 안 넣고 닫아도 해피콜 처리는 된다.

### 4-3. 예약 안내 문자
- 틀 "예약 안내"(문구 틀에서 고침): 예 `{이름}님, {병원} 예약 안내드립니다. {날짜} {시간}에 뵙겠습니다. 변경은 전화 주세요.`
- 보내기: 솔라피 키가 있으면 `/api/sms`로(받는 번호는 그 환자 연락처만, `sms_logs`에 남김). 키가 없으면(지금) 완성된 문구를 **복사** 버튼으로 주고 "병원 휴대폰으로 보냈음"을 누르면 `notified_at`에 기록(`notify_note = '복사'`).
- **자동 발송은 없다**(기존 결정). [내일 예약 안내 보내기]는 내일 예약을 한 번에 보내는 버튼이고 사람이 누른다.
- 카카오 알림톡: 솔라피 채널·템플릿 심사 뒤 같은 자리에서 방법만 바뀜.

### 4-4. 네이버 예약 N
- 길 1(지금): **[네이버 붙여넣기]** — 스마트플레이스 예약 목록을 복사해 붙이면 날짜·시간·이름·연락처·예약 번호를 읽어 `source='naver'`로 넣는다. 예약 번호로 중복을 거른다. 읽지 못한 줄은 붉게 보여 손으로 고친다.
- 길 2(확인 중): 차트 연동 방식이 열려 있으면 서버 함수로 받아 같은 표에 넣는다. "넣을 수 있다"는 말의 정체(파트너 API인지, 차트 업체 제휴인지)를 조사해 적는다.
- N 예약은 시간표에 **N** 배지, 전화번호가 있으면 환자와 연결(연락처 기준), 없으면 이름만.

### 4-5. 첫 화면·현황
- 첫 화면 요약: "오늘 예약 N명 · 내원 c". 현황: 월별 예약 수, 내원율, 노쇼 수, 출처별(네이버/접수실/해피콜).
