# 접수실 PC에서 병원 휴대폰 문자·카카오톡 쓰기

2026-11-11. 답이 필요한 문자(경과 확인·해피콜·다시 연락)는 **병원 휴대폰 번호**로 보낸다. 솔라피에 승인된 대표번호(02)는 환자 답장을 받지 못하기 때문이다.
PC에서 병원 휴대폰의 문자를 보내고 받게 해 두면, 샘이 휴대폰을 들지 않고 앱 옆에서 바로 보내고 답을 확인한다.

여기 적힌 일은 **병원 휴대폰(갤럭시)을 손에 들고 접수실 PC 앞에서** 해야 한다. 한 번만 하면 된다.

## 1. 문자 — 윈도우 "휴대폰과 연결"
1. PC에서 시작 단추 → "휴대폰과 연결"을 찾아 연다. (윈도우 11에 기본으로 들어 있다.)
2. [Android]를 고르면 QR 코드가 뜬다.
3. 병원 휴대폰에서 설정 → 연결된 기기 → **Windows와 연결**을 켜고, QR 코드를 찍는다.
   - 마이크로소프트 계정 로그인을 물으면 병원에서 쓰는 계정으로 로그인한다. 없으면 병원용으로 하나 만든다. 개인 계정은 쓰지 않는다.
4. 휴대폰에 뜨는 권한 요청(문자·연락처·알림)을 모두 허용한다.
5. PC의 "휴대폰과 연결" 창에서 [메시지] 탭에 병원 휴대폰의 문자가 보이면 끝.

PC를 켤 때 자동으로 연결되게 하려면: 휴대폰과 연결 → 설정(톱니) → 일반 → "Windows에 로그인할 때 휴대폰과 연결 시작"을 켠다.
병원 휴대폰은 PC와 같은 와이파이에 두면 가장 안정적이다. 휴대폰이 꺼져 있으면 PC에서도 못 보낸다.

## 2. 앱에서 보내기
해피콜 줄·주간 관리 줄·예약 안내에 단추가 있다.
- **[PC 문자 창 열기]**: 누르면 "휴대폰과 연결"의 새 문자 창이 받는 번호와 문구가 채워진 채로 열린다. 읽어 보고 보내기만 누른다.
  - 처음 누를 때 "이 링크를 열 앱을 고르세요"가 뜨면 **휴대폰과 연결**을 고르고 "항상"을 체크한다.
  - 문구가 비어서 열리면: 앱의 [문구 복사]를 누르고 문자 창에 붙여 넣는다(Ctrl+V).
  - 번호가 비어서 열리면: 앱의 [번호 복사]를 누르고 받는 사람 칸에 붙여 넣는다.
- 보낸 뒤 앱에서 "연락함(문자)"·"발송함"·"병원 휴대폰으로 보냈음"을 눌러 기록한다. 이 길로 보낸 문자는 앱의 문자 장부에 자동으로 남지 않는다(솔라피를 거치지 않으므로).
- 답장은 "휴대폰과 연결"의 [메시지] 탭에 뜬다. 내용을 긁어서 앱의 답변 칸에 붙여 넣는다.

휴대폰에서 앱을 열었을 때는 같은 자리에 **[문자 앱으로 열기]**가 보인다. PC가 안 될 때는 병원 휴대폰에서 앱을 열어 이걸 쓴다.

## 3. 카카오톡 — 카카오톡 PC
1. PC에 카카오톡 PC 버전을 설치한다(카카오 공식 사이트에서 내려받기).
2. 병원 휴대폰의 카카오 계정으로 로그인한다. 처음에는 병원 휴대폰 카카오톡에 뜨는 인증 번호를 PC에 넣어야 한다.
3. "이 PC를 인증된 기기로 등록"은 접수실 PC에서만 켠다.

이렇게 하면 환자가 병원 휴대폰 카카오톡으로 보낸 메시지를 PC에서 보고 답한다.

### 카카오톡 채널(병원 채널)의 1:1 채팅
- PC 브라우저에서 카카오톡 채널 관리자센터(https://center-pf.kakao.com)에 로그인 → 병원 채널 → [1:1 채팅].
- 휴대폰은 "카카오톡 채널 관리자" 앱.
- 채널 채팅은 카카오톡 PC의 일반 대화 목록에는 나오지 않는다. 관리자센터 창을 따로 열어 둔다.

### 앱 안에서는 볼 수 없다
카카오톡 대화와 채널 채팅은 카카오가 외부 프로그램에 내주지 않아, 접수실 앱 화면 안에 띄울 수 없다(공식 상담톡 연동은 대행사 계약이 필요한 유료 서비스). 앱은 문구를 만들고 누가 언제 무엇을 보냈는지·답이 왔는지를 기록하는 곳이고, 실제 대화 창은 옆에 띄워 쓴다.

## 4. 화면 배치 권장
왼쪽 절반에 접수실 앱, 오른쪽 위에 "휴대폰과 연결" 문자 창, 오른쪽 아래에 카카오톡 PC(또는 채널 관리자센터).

## 주의
- 병원 휴대폰 번호로 나가는 문자는 통신사 요금제의 무료 문자 한도를 쓴다. 하루 20~30통씩 나눠 보낸다.
- PC를 여러 사람이 쓰니, 퇴근할 때 카카오톡 PC는 잠금(Ctrl+L) 또는 로그아웃한다.
- 환자 문자가 PC 화면 알림으로 뜬다. 대기실에서 보이는 모니터라면 "휴대폰과 연결" 설정에서 알림 배너를 끈다.
