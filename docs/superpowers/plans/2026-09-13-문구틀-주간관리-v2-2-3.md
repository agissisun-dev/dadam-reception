# 안내문 틀 (V2-2) · 주간 환자 관리 문자 (V2-3) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 접수실이 앱에서 문구 틀을 관리하고, 업무 등록 때 틀을 고르며, 주간 관리 대상 환자에게 회차별 문구를 복사해 보내고 답변·원장 지시를 왕복시킨다.

**Architecture:** V1·V2-1과 같은 구조. `templates` 표 하나에 종류(kind)로 업무 안내문과 주간 관리 문구를 함께 둔다. 환자 표에 주간 관리 상태 6칸을 더하고 `weekly_contacts`에 기록을 쌓는다. 날짜·회차·문구 선택 규칙은 순수 함수(`lib/weeklyRules.ts`)로 분리해 Vitest로 검증한다.

**Tech Stack:** Next.js 16, React 19, Tailwind 4, supabase-js 2, Vitest

**Spec:** `docs/superpowers/specs/2026-09-13-문구틀-주간관리-v2-2-3-design.md`

## Global Constraints

- 버튼 이름 스펙 그대로: [문구 복사] [발송함] [내원해 건너뜀] [답 없음 → 다음 주] [휴면] [연락 제외] [답변 기록] [원장님 확인 요청] [확인 완료] [주간 관리 시작] [중지] [다시 시작]
- 기본 요일 화요일(2), 기본 주기 1주. 회차 5 이상은 4주차 문구.
- 자동 발송·자동 휴면 없음. 무응답 4주 이상은 배지만.
- 문구는 치료 안내 범위. seed 문구에 할인·이벤트 없음.
- 기존 표·화면(tasks, 해피콜)은 건드리지 않는다. 업무 등록 화면에는 select 하나만 추가.
- 기능 단위마다 커밋.

### Task 2: 타입 + 규칙 함수 (테스트)
- `lib/types.ts`: `Template`, `WeeklyContact`, `WeeklyAction`, `Patient`에 weekly_* 6칸, `WeeklyRow = Patient & { last: WeeklyContact | null; noReplyStreak: number }`
- `lib/weeklyRules.ts`:
  - `nextWeeklyDate(fromISO, weekday, intervalWeeks, includeToday)`: 시작 시 includeToday=true → from 이후 첫 지정 요일(당일 포함). 처리 후 includeToday=false → 예정일 + interval*7.
  - `effectiveRound(round)`: min(round, 4)
  - `pickWeeklyTemplate(templates, condition, round)`: condition·round 일치 → 없으면 condition null 공통 → 없으면 null
  - `consecutiveNoReply(contacts desc)`: 최근부터 연속 'no_reply' 수
  - `weekEndISO(today)`: 이번 주 일요일
- 테스트: 화요일 계산(오늘이 화요일이면 오늘), 주기 2주, 회차 캡, 틀 선택 우선순위, 무응답 연속 계산
- 커밋 `feat: 주간 관리 규칙 함수 (다음 발송일, 회차, 문구 선택, 무응답)`
